# GlowTrade 🌟

Высокопроизводительный, надежный и на 100% защищенный от дюпов плагин безопасного обмена ресурсами (`/trade`) между игроками для серверов **Paper / Purpur / Spigot** (версии **1.16.5 – 1.21+**).

* **Авторы:** ejyqyl / atomicsqd
* **Основной пакет:** `ru.atomicsqd.glowtrade`
* **Стиль оформления:** ReallyWorld / GlowTrade (фирменный градиент `#FFA500` -> `#FFD700`, префикс `GlowTrade >> `)

---

## Особенности плагина

### 1. Система запросов и удобство взаимодействия
- **Shift + ПКМ по игроку**: мгновенная отправка предложения обмена при взаимодействии.
- Взаимные запросы: если игрок A отправляет запрос игроку B, который уже отправил запрос игроку A, трейд запускается автоматически без лишних подтверждений.
- Таймаут запросов (по умолчанию 30 секунд).
- Включение/выключение входящих запросов (`/trade toggle`).

### 2. Интерфейс в стиле ReallyWorld (54 слота)
- **Слоты предложений:**
  - Левая сторона (0-3, 9-12, 18-21, 27-30) — 16 слотов Игрока 1.
  - Правая сторона (5-8, 14-17, 23-26, 32-35) — 16 слотов Игрока 2.
- **Разделители и кнопки управления:**
  - Слоты 4, 13, 22, 31, 49 — стильное разделительное стекло с градиентом.
  - Слоты 36-39 — кнопки статуса готовности Игрока 1 (Красный: не готов / Зеленый: готов).
  - Слоты 41-44 — кнопки статуса готовности Игрока 2.
  - Слот 40 — индикатор таймера (ожидание или 3-секундный таймер со звуковым тиканьем).
  - Слоты 45-48, 50-53 — защищенные фоновые заполнители.
- **Anti-Anvil & Градиенты:**
  - Все названия элементов GUI оформлены плавным HEX-градиентом.
  - Полное удаление навязчивого наковаленного курсива (`§o`) с элементов интерфейса.
  - Защита от скама: запрет выставлять в трейд предметы, переименованные в наковальне (`block-anvil-renamed-items: true`), что предотвращает мошенничество с подделкой донат-валюты и кейсов.

### 3. Абсолютная защита от дюпов (Anti-Dupe & Anti-Scam)
- **Атомарные операции в главном тике:** исключены любые состояния гонки и асинхронные задержки при передаче ресурсов.
- **Блокировка опасных кликов:**
  - Полный запрет сбора предметов двойным кликом (`COLLECT_TO_CURSOR`).
  - Переопределен ванильный Shift-клик: предметы из инвентаря игрока переносятся **только** в свободные ячейки своего предложения; перемещение в разделители, кнопки или чужие слоты технически невозможно.
  - Защита хотбар-свапов (`1-9` и `F`).
  - Валидация `InventoryDragEvent` (запрет задевать любые слоты, кроме своих).
- **Anti-Scam:** Любая попытка подменить, добавить или убрать предмет после нажатия готовности или во время 3-секундного таймера мгновенно сбрасывает готовность обоих игроков, отменяет отсчет и проигрывает предупреждающий звук.
- **Гарантированный возврат предметов:**
  - При закрытии меню (Esc, кик, краш, смерть, урон, превышение дистанции) все выставленные предметы немедленно возвращаются владельцам.
  - Если инвентарь переполнен — предметы безопасно выпадают под ноги (`world.dropItemNaturally`) с отправкой предупреждения.
  - При отключении плагина / перезагрузке сервера (`onDisable`) все активные трейды принудительно отменяются с полным возвратом предметов до выгрузки мира.

### 4. Интеграции и совместимость
- **PvP-режим:** поддержка плагинов CombatLogX и PvPManager, а также собственный трекер боя (запрет трейда в бою).
- **Кросс-версионность (1.16.5 – 1.21+):** безопасный резолвер звуков `SoundUtil` с фоллбеками.
- **Blacklist:** возможность запретить материалы, CustomModelData или NBT/PDC теги (`untradeable`, `nodrop`).

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/trade <ник>` | Отправить запрос на обмен игроку | `glowtrade.use` (по умолчанию: всем) |
| `/trade accept [ник]` | Принять входящий запрос на обмен | `glowtrade.use` |
| `/trade deny [ник]` | Отклонить входящий запрос на обмен | `glowtrade.use` |
| `/trade toggle` | Включить/выключить прием запросов | `glowtrade.use` |
| `/glowtrade reload` | Перезагрузить файлы конфигурации | `glowtrade.admin` (по умолчанию: OP) |

## Сборка проекта

Для сборки `.jar` файла используйте Maven:

```bash
mvn clean package
```

Собранный плагин будет находиться по пути:
`target/GlowTrade-1.0.0.jar`
