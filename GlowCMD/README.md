# GlowCMD

**GlowCMD** — это облегчённый, ультра-оптимизированный и модульный аналог **EssentialsX** и **CMI**, созданный для высоконагруженных и современных серверов Minecraft (Paper, Purpur, Spigot).

**Автор:** ejyqyl  
**Лицензия:** GNU General Public License v3.0 (GPL-3.0)

---

## 1. Описание

GlowCMD решает главную проблему классических плагинов Essentials и CMI — избыточный оверхед, синхронные блокировки основного тика сервера при сохранении файлов, постоянное чтение YAML-конфигураций при каждом вызове команд и загромождённость легаси-кодом.

В GlowCMD все данные кэшируются в памяти с доступом **O(1)**, запись файлов на диск выполняется строго в **асинхронных потоках**, а система локализации вынесена в единый конфигурационный файл `messages.yml` с поддержкой Minecraft-кодов `&0`-`&f`, HEX-градиентов `&#RRGGBB` и защитой от падений.

---

## 2. Ключевые возможности

- **✓ Архитектура нового поколения:** Чистая модульная структура классов без монолитных спагетти-кодов.
- **✓ Максимальная производительность:** Конфигурации, дома, варпы и сообщения загружаются в оперативную память один раз.
- **✓ Асинхронное сохранение данных:** Команды `/setspawn`, `/setfirstspawn`, `/sethome`, `/setwarp` не вызывают лагов и подвисаний TPS.
- **✓ Модные фичи из CMI:**
  - `/rtp` (случайная безопасная телепортация в радиусе);
  - `/anvil`, `/craft`, `/ec` (виртуальные рабочие станции на ходу);
  - `/tpcancel` (отмена исходящего запроса телепортации);
  - `/back` (возврат на предыдущую точку не только после телепортации, но и при смерти).
- **✓ Продвинутая система TPA:** Запросы с таймаутом (60 сек), подтверждением (`/tpaccept`) и отклонением (`/tpdeny`).
- **✓ Система домов и варпов:** Лимиты домов через права (`glowcmd.homes.<число>`), просмотр списков и таб-комплит.
- **✓ Инструменты модерации:** `/vanish` (полное скрытие от игроков), `/invsee`, `/broadcast`, `/sudo`, `/ping`, `/seen`.
- **✓ Управление миром:** `/time` (`/day`, `/night`), `/weather` (`/sun`, `/rain`).
- **✓ Приватные сообщения:** `/msg` и быстрый ответ `/reply` (`/r`).
- **✓ 100% настраиваемый `messages.yml`:** Возможность изменения любого сообщения, плейсхолдеров, цветов или отключения сообщения через `""`.

## 3. Список команд

### 3.1. Спавн (Spawn Engine)
| Команда | Описание | Permission |
|---|---|---|
| `/spawn` | Телепортация на основной спавн сервера | `glowcmd.spawn` |
| `/setspawn` | Установка точки основного спавна | `glowcmd.setspawn` |
| `/setfirstspawn` | Установка точки первого появления новичков | `glowcmd.setfirstspawn` |
| `/glowcmd reload` | Перезагрузка всех конфигов, сообщений и баз данных | `glowcmd.reload` |

### 3.2. Утилиты игрока (Player Utilities)
| Команда | Алиасы | Описание | Permission |
|---|---|---|---|
| `/heal [player]` | — | Исцеление здоровья, голода, тушение огня и снятие эффектов | `glowcmd.heal`, `glowcmd.heal.others` |
| `/feed [player]` | — | Полное утоление голода и сатурации | `glowcmd.feed`, `glowcmd.feed.others` |
| `/fly [player]` | — | Переключение режима полёта | `glowcmd.fly`, `glowcmd.fly.others` |
| `/god [player]` | — | Режим неуязвимости (бессмертия) | `glowcmd.god`, `glowcmd.god.others` |
| `/speed <1-10> [player]` | — | Регулировка скорости ходьбы или полёта | `glowcmd.speed`, `glowcmd.speed.others` |
| `/gamemode <режим> [player]` | `/gm`, `/gmc`, `/gms`, `/gma`, `/gmsp` | Смена игрового режима (0, 1, 2, 3) | `glowcmd.gamemode`, `glowcmd.gamemode.others` |
| `/clear [player]` | `/ci`, `/clearinventory` | Очистка инвентаря игрока | `glowcmd.clearinventory`, `glowcmd.clearinventory.others` |
| `/hat` | — | Надеть предмет из руки на голову | `glowcmd.hat` |
| `/workbench` | `/craft`, `/wb` | Виртуальный верстак | `glowcmd.workbench` |
| `/enderchest` | `/ec` | Виртуальный эндер-сундук | `glowcmd.enderchest`, `glowcmd.enderchest.others` |
| `/anvil` | — | Виртуальная наковальня (фича CMI) | `glowcmd.anvil` |
| `/top` | — | Телепортация на самый верхний безопасный блок над игроком | `glowcmd.top` |
| `/suicide` | — | Самоубийство | `glowcmd.suicide` |

### 3.3. Телепортация (Teleportation Suite)
| Команда | Описание | Permission |
|---|---|---|
| `/tp <player> [target]` | Телепортация к игроку или телепортация одного игрока к другому | `glowcmd.tp`, `glowcmd.tp.others` |
| `/tphere <player>` | Телепортация указанного игрока к себе | `glowcmd.tphere` |
| `/tpa <player>` | Отправить запрос на телепортацию к игроку | `glowcmd.tpa` |
| `/tpahere <player>` | Отправить запрос игроку на телепортацию к вам | `glowcmd.tpahere` |
| `/tpaccept [player]` | Принять входящий запрос на телепортацию | `glowcmd.tpaccept` |
| `/tpdeny [player]` | Отклонить запрос на телепортацию | `glowcmd.tpdeny` |
| `/tpcancel` | Отменить свой исходящий запрос (фича CMI) | `glowcmd.tpcancel` |
| `/back` | Возврат на предыдущее место телепортации или точку смерти | `glowcmd.back` |
| `/rtp` (алиас: `/tpr`) | Случайная безопасная телепортация в мире (фича CMI) | `glowcmd.rtp` |

| `/delhome [name]` | Удалить точку дома | `glowcmd.delhome` |

| Команда | Описание | Permission |
|---|---|---|
| `/vanish` (алиас: `/v`) | Полная невидимость (скрытие из таба и мира) | `glowcmd.vanish` |
| `/invsee <player>` | Просмотр и редактирование инвентаря игрока в реальном времени | `glowcmd.invsee` |
| `/broadcast <text>` (алиас: `/bc`) | Объявление на весь сервер с поддержкой префикса и цветов | `glowcmd.broadcast` |
| `/sudo <player> <c:чат\|команда>` | Выполнение команды или отправка текста от имени игрока | `glowcmd.sudo` |

## 4. Система прав (Permissions)

- `glowcmd.*` — полный доступ ко всем командам (по умолчанию у OP).
- `glowcmd.homes.<количество>` — лимит домов для игрока (например, `glowcmd.homes.5`, `glowcmd.homes.10`).
- `glowcmd.homes.unlimited` — неограниченное количество домов.
- `glowcmd.vanish.see` — право видеть игроков, находящихся в ванише.
- `glowcmd.seen.ip` — право видеть IP-адрес игрока в `/seen`.

## 5. Файловая структура данных

Все данные хранятся в папке `plugins/GlowCMD/`:
```
plugins/GlowCMD/
├── config.yml        # Основные настройки спавна и смерти
├── messages.yml      # 100% пользовательских сообщений и цветов
└── data/
    ├── spawn.yml     # Точки обычного и первого спавна
    ├── homes.yml     # База домов всех игроков
    └── warps.yml     # База глобальных варпов
```

## 6. Сборка и тестирование

Проект собирается стандартным Maven:

```bash
mvn clean test      # Запуск модульных тестов (35 тестов)
mvn clean package   # Сборка JAR-файла
```

Готовый артефакт:
`target/GlowCMD-1.0.0.jar` (~123 КБ).
