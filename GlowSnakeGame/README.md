# GlowSnakeGame

Плагин классической мини-игры «Змейка» (Snake) в графическом сундучном интерфейсе (Chest GUI на 54 слота) для серверов Minecraft (**Paper / Purpur / Spigot 1.16.5–1.20+**).

**Авторы**: Ejyqyl, GlowDev

---

## Особенности

- **Интерфейс 54 слота**:
  - Внешний периметр (строки 0 и 5, столбцы 0 и 8) — стены из красного стекла/барьеров.
  - Игровое поле $4 \times 7$ (28 слотов) из серого стекла.
  - Зеленый блок головы змейки (`LIME_CONCRETE`) с указанием направления движения и текущего счёта.
  - Сегменты тела змейки (`GREEN_STAINED_GLASS_PANE`).
  - Случайно генерируемые яблоки (`APPLE`) на свободных клетках поля.
- **Управление WASD (`PlayerMoveEvent`)**:
  - Игрок фиксируется на месте во время игры.
  - Сервер отслеживает вектор перемещения относительно взгляда игрока (W — вверх, S — вниз, A — влево, D — вправо).
  - Строгий запрет мгновенного разворота на 180° с буферизацией вводов для предотвращения случайного самопересечения.
  - Опциональное вспомогательное управление кликами по краям меню (для клиентов без мода *InvMove*).
- **Игровой цикл**:
  - Настраиваемая скорость через `tick-delay` в `config.yml` (по умолчанию 5 тиков).
  - Поедание яблока удлиняет змейку, начисляет +1 очко и проигрывает звук `ENTITY_EXPERIENCE_ORB_PICKUP`.
  - Проверка столкновения со стенами и собственным телом с воспроизведением звуков поражения `ENTITY_VILLAGER_NO` и `BLOCK_ANVIL_LAND`.
  - Экран Game Over с отображением итогового счета, личного рекорда и кнопкой мгновенного перезапуска.
- **Безопасность и оптимизация**:
  - Полная блокировка перетаскивания и забирания предметов (`InventoryClickEvent`, `InventoryDragEvent`).
  - Мгновенная очистка памяти и отмена таска `BukkitTask` при закрытии инвентаря игроком (`InventoryCloseEvent`) или выходе с сервера.
  - Защита игрока от урона, голода и выброса предметов во время игровой сессии.
  - Сохранение личных рекордов игроков в `scores.yml`.

## Команды и права

| Команда | Алиасы | Описание | Право |
|---|---|---|---|
| `/snake` | `/sgame`, `/snakegame` | Открыть меню и запустить игру | `glowsnake.play` (по умолчанию: всем) |
| `/snake reload` | — | Перезагрузить конфигурацию плагина | `glowsnake.admin` (по умолчанию: OP) |
| `/snake top` | — | Просмотреть топ 10 рекордов игроков | `glowsnake.play` |
| `/snake help` | — | Справка по командам | — |

## Сборка и установка

1. Склонируйте проект и выполните сборку с помощью Maven:
   ```bash
   mvn clean package
   ```
2. Скопируйте готовый файл `target/GlowSnakeGame-1.0.0.jar` в папку `plugins/` вашего сервера Paper / Purpur.
3. Запустите сервер или используйте PlugMan / перезагрузку.
